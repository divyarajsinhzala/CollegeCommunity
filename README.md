# College Community Platform 🎓

A dynamic, full-stack campus management system built with C# ASP.NET MVC and Entity Framework. This platform bridges the gap between students and administration by unifying campus life into a single, premium glass-neumorphism interface.

## 🚀 Key Features

* **Role-Based Access Control:** Distinct, secure dashboards for Students and System Administrators.
* **Club Memberships:** A digital directory where students can explore, join, and leave campus organizations.
* **Secure Chatrooms:** Isolated, peer-to-peer messaging channels locked to enrolled clubs.
* **Global Moderation:** Admin tools to delete messages, purge old database records, and trigger a global "Read-Only" chat lockdown.
* **Live Broadcasts:** Instant campus announcements and urgent administrative alerts.
* **Help Desk:** Built-in ticketing system for students to submit issues directly to administration.
* **Maintenance States:** Global toggle to lock student access during system updates.

## 🛠️ Technology Stack

* **Backend:** C# ASP.NET MVC 5
* **Database:** SQL Server / Entity Framework (Code-First)
* **Frontend:** HTML5, CSS3 (Custom Glass-Neumorphism design), Vanilla JS
* **Icons & Assets:** FontAwesome 6
